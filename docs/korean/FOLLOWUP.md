## 완료 표시 원칙

실제 앱 시험, 브라우저 시험, 코드 검사와 정적 검토를 구분한다. 과거 통과 기록을 새 후보의 통과로 표시하지 않는다. 계정·OS 권한·외부 서비스가 필요한 항목은 관찰한 범위대로 남긴다. 사람의 최종 직접 확인과 PR 제출은 대신 완료 처리하지 않는다.

## 이번에 보완한 동작

- 연속 언어 변경은 최신 요청만 설정을 저장하고, 네이티브 메뉴 호출을 순서대로 처리한다. 다른 창의 저장 변경도 적용한다.
- 언어 로드 실패는 설정 화면을 다시 열어도 보이며, 실패한 선택을 기억한다. 저장·메뉴 갱신 실패도 별도 재시도 버튼으로 복구할 수 있다.
- 실험 기능의 이름·설명을 한국어로 표시한다. 번역은 표시 부분에만 적용하고 manifest·기능 ID·저장값은 그대로 보존한다.
- 앱 내 알림 영역의 접근성 이름을 선택 언어로 표시한다.
- 공개 패치의 정확한 diff 구간과 리터럴만 해석한다. 고정 입력 해시를 검사하며, 커밋된 스냅샷으로 네트워크 없이 재생성한다. `pnpm check`가 생성 결과의 최신 상태도 검사한다.
- 개인 빌드 번호와 소스 지문을 번들에 기록한다. 고정 식별자는 유지하며 빌드 도중 소스가 바뀌면 완료를 거부한다.
