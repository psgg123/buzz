## 실제 로컬 흐름과 남은 조건

빌드 2에서 실제 Codex 에이전트가 지정 시험 폴더에 한글 파일을 쓰고 다시 읽어 응답했으며, 중지 후 자식 프로세스 종료를 확인했다. 비공개 포럼의 글·답글, 프로젝트·캔버스 저장/재진입, Pulse 게시·좋아요, 내부 메시지 링크를 확인했다. 워크플로는 고유 시험 문구로 한 번 실행해 한국어 결과 메시지를 생성한 뒤 다시 비활성화했다.

사용자는 macOS 알림을 허용했고 “알림이 왔고 클릭하면 해당 메시지로 이동함”이라고 확인했다. 이후 네이티브 경로의 `item` 값과 메시지 ID가 일치하는 것도 확인했다. 이는 빌드 2의 실제 배너/클릭 확인이며, 빌드 3의 이름·권한 유지 확인은 따로 한다.

빌드 3의 키체인 접근을 사용자가 허용한 뒤 기존 `korean-qa` 신원, Local Dev 이력, 한국어 UI·네이티브 메뉴, 두 줄의 한글 초안과 `{{p0}}` 원문을 확인했다. 알림 설정은 “켜짐”, 데스크톱 알림은 활성화된 상태였다. 실제 로컬 Git 저장소의 개요·파일 탭·71 B README가 정상으로 열렸고 한글과 변수 형태의 원문이 그대로 표시됐다. 빌드 2에서 재현한 Git helper 경로 오류는 이 설치본에서 해결됐다.

외부 개인 스킴 링크는 브라우저 보안 정책에서 호출 자체를 차단했다. 다른 브라우저나 간접 실행으로 우회하지 않았으며, 실제 OS 링크 처리 성공으로 표시하지 않는다. 최종 후보의 조합 Enter·Shift+Enter와 README 열기는 사람의 직접 확인을 요청한 상태다. 근거는 `native-build3.json`에 별도로 기록하여 이전 빌드의 결과와 구분한다.

빌드 3 교체 전 종료 상태의 프로필 16개, WebKit 16개, nest 34개, 앱 11개 파일을 복사하고 해시 일치를 확인했다. 공식 앱은 기존 계정 화면으로 실행되는 것을 확인한 후 정상 종료했다. VoiceOver는 시험 전의 꺼짐 상태로 복원했다. 시험용 미리보기 기능 4개와 마지막 fixture 인스턴스는 네이티브 인수 후 정리한다.
