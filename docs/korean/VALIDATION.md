# 첫 개발판 검증 기록

2026-10-23, macOS arm64, `desktop-v0.5.28` 기준입니다. 이 기록은 첫 개발판의 확인 범위이며 전체 계획 완료나 upstream 제출 준비 완료를 뜻하지 않습니다.

| 확인 항목 | 결과 |
|---|---|
| 원본 desktop 기준선 | 단위/DOM 테스트 6,989개 통과, 프런트엔드와 네이티브 빌드 및 격리 첫 실행 확인 |
| 수정 후 desktop 테스트 | 단위 테스트 6,842개 + jsdom 테스트 164개, 합계 7,006개 통과 |
| 정적 검사 | `pnpm typecheck`, `pnpm check`, 파일 크기 ratchet, `git diff --check` 통과. Biome 경고 3개는 로그에 기록 |
| 기존 브라우저 회귀 | 실제 Chrome의 임시 프로필과 mock bridge에서 선택한 기존 테스트 4개 통과 |
| 언어 전환 | 실제 시험 화면에서 한국어→영어→한국어 즉시 전환, 메뉴 묶음과 미리보기 갱신 확인 |
| 설정 복원 | 브라우저 새로고침 후 한국어 선택 복원 확인 |
| 사용자 값 보존 | 한글·영문·템플릿 기호가 섞인 초안이 설정 이동과 언어 변경 후에도 동일함을 확인 |
| 작은 화면 | 1280×800 및 900×650 모양 화면 확인. 900×650에서 문서 수평 넘침 없음 |
| macOS 앱 | `mesh-llm` 기능을 포함한 release `.app` 생성. 최종 로컬 서명 사본의 한국어 첫 화면 확인 |
| macOS 메뉴 | 앱 소유의 편집·보기·윈도우·도움말과 편집 하위 항목 한국어 확인. OS 삽입 메뉴는 OS 언어를 따름 |
| 패키지 | 최종 사본과 빌드 번들 바이트 비교 및 `codesign --verify --deep --strict` 통과 |
| 원본 보존 | 기존 설치 앱의 메인 실행 파일 SHA-256이 작업 전후 동일 |

브라우저 회귀 4개는 메시지 전송, SVG 아바타 clip path, 에이전트 공개 접근 경고, 원격 제공자 실행 위치 경고입니다. 전체 브라우저 테스트가 통과했다고 확대 해석하지 않습니다. 시험 데이터는 mock이며 운영 대화를 전송하지 않았습니다.

번역 자원은 3,358개이고, 소스에 연결한 `uiT`/`uiMessage` 호출은 4,152곳입니다. 이 수치는 전체 UI 번역률이 아닙니다. 추출기의 영문 후보 101개에는 브랜드·URL·코드도 포함되며, 별도로 동적 문구와 화면 문맥을 검토해야 합니다.

보조 실행 파일은 동일 버전 설치본에서 재사용했고 새로 컴파일하지 않았습니다. 개인용 번들 안의 사본을 로컬에서 재서명했으므로 원본 해시와 패키지 해시는 따로 기록합니다. 로컬 ad-hoc 서명은 Block 배포 서명이나 Apple 공증을 대신하지 않습니다.

검증 중 수정한 항목은 번역 후 공백이 사라진 표시 회귀, 언어 변경 후 남는 UI 캐시, 비동기 React Query 관찰 결과를 타이머 완료 전에 검사하던 테스트 대기 방식입니다. 권한이나 전송 판정의 테스트 기대값은 유지했습니다.
