## 남은 직접 확인

최종 설치본의 조합 Enter·Shift+Enter와 저장소 파일 열기 직접 확인은 아직 대기 중입니다. 이를 완료했다고 주장하지 않으며 PR은 Draft로 제출했습니다. 이전에 제공된 AGENTS.md 지침은 사용자에 의해 철회되었습니다.

사용자 확인 순서:

1. Finder에서 개인용 앱을 열고 설정 → 모양 → 언어를 한국어 → English → 한국어로 바꿉니다. 메뉴와 화면이 함께 바뀌어야 합니다.
2. 한글·영문·`{{p0}}`가 섞인 초안을 입력하고 언어를 바꿉니다. 초안이 그대로여야 합니다. 한글 조합을 확정하는 Enter는 메시지를 조기에 보내지 않아야 합니다.
3. 앱을 종료·재실행합니다. 선택한 언어와 같은 신원이 복원돼야 합니다.
4. 시험 공간에서 메시지, 한글 파일명 첨부와 다운로드, 시험 에이전트 시작·중지를 확인합니다.
5. 한글판을 종료하고 공식 앱을 열어 기존 계정과 설정을 확인합니다.

제출 당시 원본 main은 위 기준 SHA와 같았고, GitHub에서 충돌 없음 및 DCO Check 통과를 확인했습니다. 기여 브랜치는 14개 커밋·761개 파일이며 PR의 head는 변경하지 않았습니다. 게시 본문과 확인 기록은 `local/publication/2026-10-25/`에 보관합니다.
